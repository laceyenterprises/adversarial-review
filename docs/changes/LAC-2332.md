## Interface changes

A canonical deferral preserves the exact source, check identity and cleanup
receipts beyond run scratch. Unsafe or unreadable custody holds its target and
asks for one operator decision. A clean matching-target source with confirmed
cleanup is marked continued and returns to existing per-head retry backoff and
notification. Legacy retry entries alone and corrupt retry files do not hold
unrelated heads; new unsafe observations retain explicit `custodyRequired`
fallback evidence. Corrupt retry files remain preserved for recovery.

Teardown retries incomplete bundling before refusing reclamation and omits
unavailable prerequisites so it can create a self-contained bundle. A missing
source receipt can establish matching-target source only when cleanliness is
not explicitly false. Continuation waits up to one second for a contended lock;
the controller retries post-publication completion three times without another
push. Standalone UNKNOWN accepts an all-local-pass selection without CI coverage
identity, while every UNKNOWN merge still requires declared green exact-head
contexts, including legacy receipts. Tests use stable exact assertions at the
Node 22.10 engine floor and pin controller coverage/cleanup fields.

Final review 6044256636 added a distinct custody stop for conflict repair,
exit 125 for every unconfirmed cleanup, and a visible mirror diagnostic when
the full selection is unavailable. Teardown retries local Git asynchronously
only in the verified worker checkout, paces failures per hold, and prunes its
temporary ref after persisting the bundle receipt. Exact-source publication
can satisfy continued custody without a bundle. The watcher attempts the hold
lock once per pass, and an unreadable retry record holds the corresponding
ended launch's retry and surfaces one operator notice. Queue finalization
checks completeness again for legacy remediated UNKNOWN receipts with declared
green CI. Signed exact-head clean admissions retain the production CI-only
UNKNOWN shape and can merge on declared green contexts.

The main integration teaches the publication reader to accept a valid rebase
base while retaining support for older bindings. The controller settles
custody after the fenced push before handling a changed replay's exact-head
review handoff. Canonical docs and state
projections match the reconciled implementation; the lifecycle graph, required
checks and CI configuration remain unchanged. Combined operator release tooling
and host-scoped fault paging remain previously recorded follow-ups.

Review 6044981731 keeps the mirror setup-fault UNKNOWN/custody behavior.
Host-scoped fault paging and deduplication remain operator follow-up work.
Post-publication custody exhaustion now exits 75 after three attempts. The
infrastructure-page regression counts delivery before returning, so swallowed
assertions cannot hide a page. The runbook includes an executable backup
