# LAC-2338 · HAMWRITERREFUND-01

## Summary

Agent OS #11502 had a repaired, green head
`b16908c8c6a748d4627eb6a068c7c7e63d0b6658` with clear strict source and pack
checks. Closer `lrq_faa19477` spent 37 minutes in its controller. The preserved
native lease evidence shows one charged attempt and fourteen retryable releases
with a future cooldown for that head. The last transport artifacts were empty,
so the other releases cannot be attributed to the proof timeout recorded in one
native comment. Operator cancellation after steering was refused drained the
closer group. [Native closer comment](https://github.com/laceyenterprises/agent-os/pull/11502#issuecomment-7131253236)

`hammer-merge.sh` gave the legacy lane its existing admission deadline.
Inside the lane, `legacy-lane-write.mjs` separately bounded the fresh review
proof by the existing load-aware read budget and the remaining command budget.
The old proof-timeout audit mapped to a same-head redrive. The shell's lease
release classified it as retryable, and `recordNoMergeRelease` zeroed the
consecutive chargeable release count. Once the finite cooldown expired, the
same inputs could re-enter. An ambiguous command error could also re-enter the
bounded transport loop after its fresh gate read. PR #2030 addresses deferred
source custody. PR #2051 addresses late conflict repair.

## Interface changes

The hammer records writer intent before the click and reads GitHub after the
writer returns. `merge-writer-deferred` retains the head, base and writer
diagnostics in the AMA audit and assigns one closure recovery handoff per head.
An open PR observation and an unknown write remain distinct. A confirmed
GitHub merge after an ambiguous write settles terminal state without own-merge
credit. A later attempt needs changed live inputs and all ordinary closure
gates. The watcher and daemon read the live branch ref for base movement
because the PR payload can contain a historical base SHA.

## Verification

Offline regressions cover proof timeout, ambiguous transport with open,
merged or moved-head readback, unavailable readback, suppression of repeated
writes and pages, changed-base retry, shared lease cleanup, and redacted stderr.
