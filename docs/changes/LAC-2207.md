# LAC-2207 — SQLite worker teardown during the dependency update

PR #1905's hosted Node 22 run completed the individual assertions in
`finalization-shadow-pattern.test.mjs` before the SQLite native addon failed
during worker cleanup. The concurrent-append fixture now waits for normal
worker exit as well as the append result. Its cleanup forcibly stops only
workers left alive by a failure, then closes the parent store and removes
the temporary database. The same concurrent deduplication assertions remain.

This change retains the proposed better-sqlite3 13.1.1 lock entry. A passing
Linux Node 22 run is required to verify whether orderly shutdown resolves the
observed native crash.
