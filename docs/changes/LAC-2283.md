# LAC-2283

## Summary

A GitHub 401 interrupted guarded remediation publication with the worker's
commit still local. The worker reported `kind: github-auth`, which the strict
reply validator rejected. The guarded publisher now supplies a reply-ready
blocker and records the exact commit and remote lease independently of reply
validation.

An exited round with a current auth or stale-lease refusal holds for
owner recovery. Proven credential-only broker outages retain the existing
uncharged thirty-second refund, including native job-bound invocations. HQ
not-found liveness proves exit; preservation refusals precede manual-inspection
reply handling. Publisher diagnostics remain available with credential/path
redaction and fixed reply-safe blocker text. The consumer verifies the checkout
and saves a verified bundle where ownership permits. A running worker keeps custody. Invalid
replies remain invalid and cannot request re-review.

## Interface changes

The publisher accepts `--job-id` for follow-up invocations and
`--expected-candidate` for an explicit recovery attempt. Failure sidecars
include job and PR identity, the exact lease and the reply-ready blocker.
The stopped job records the refusal and retained source evidence. Handoff
bundles exclude history reachable from the remote lease and require their
header prerequisites for restoration; unavailable prerequisites retain checkout
evidence. Foreign-owned checkouts
are checked before Git inspection. [Refusal evidence contract](../data-model/follow-up-jobs.md#refused-remediation-publication-remlabel-01)
