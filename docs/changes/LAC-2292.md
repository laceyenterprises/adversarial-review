# LAC-2292

## Summary

The native owner logs for Agent OS #11348 and #11352 show local no-progress
watchdogs at 309,411 ms and 286,670 ms. AGY emitted an interrupted, empty
result during teardown. Both wrapper stderr tails lost the stall marker at the
classifier's 2 KiB boundary. The watcher recorded an ordinary failed attempt
on each head. Stored-row classification still sees the stall marker and
excludes those historical rows from generic command-failure recovery. Root
owns their exact-head recovery. An offline subprocess fixture reproduced the
misclassification.

## Interface changes

The native reviewer wrapper uses a reserved exit status for a typed model
stall. The direct adapter routes it to the existing session-fenced release
and cascade backoff. A bare AGY interruption retains ordinary command-failure
recovery. GitHub budget deferral has a separate exit status and retains its
reset hold. The watcher checks for a posted review before charging a matching
operator-cancelled claim. Unattributed signals and daemon shutdown remain
recoverable. Late cancellation cannot overwrite a replacement claim.
The watcher matches the cancellation receipt by session and head when the
claim has no recorded PGID. Known PGIDs must agree when both are present.
The previous size-failure statement exports remain available as aliases.
