# LAC-2331 — Review currency across native remediation and Hammer rebases

## Summary

Agent OS PR #11456 had an authoritative review on `97435b07`, a daemon-completed
native remediation at `f879b8d2`, and an authenticated Hammer publication at
`9f801d05`. The shared review reader omitted the native round, and the Hammer
range validator tried each source independently. Both lost the reviewed head
when the rebase removed it from Git ancestry.

Both paths now use the daemon's completed-job records and authenticated Hammer
comments to prove a chain ending at the exact live head. Repeated rebases can
extend the chain through additional exact Hammer edges. Source preservation
and reversal authority remain separate merge checks.

The final live Hammer gate passes the service root into the shared review
proof. A late change to a pre-round review now invalidates the terminal audit
when a completed native round and authenticated Hammer publication establish
currency. The closure runbook describes the independent exact-head proof
available when a comparison read fails.

## Interface changes

The shared reader and Hammer range validator take the local review service
`rootDir` for completed rounds. The range validator also takes `prNumber` and
reads the protected records directly. The completed-job schema stays the same.

## Verification

The two offline reproduction cases failed on unfixed main. The fixtures also
exercise repeated rebases, missing and malformed records, wrong repo and PR,
forged authorship, endpoint tampering, branch resets, and independent patch
proof after a capped comment read.

The isolated regression and daemon-audit suites passed all 38 tests after
reusing the canonical source-reversal fixture. The 11-file offline run passed
577 of 578 tests before that fixture correction, including the watcher claim
loop and state-machine smoke. Lint passed with zero errors, contract typecheck
passed, and the walkthrough produced three byte-stable deliveries.

The local full suite reached its 1,800-second deadline with 694 files still
queued. The existing native mixed-round and watcher fixtures used placeholder
commit IDs that the stricter record reader rejected in the first hosted run.
The fixtures now use full SHAs and a scoped repository name. The three-file
rerun passed all 193 cases, and six additional consumer suites passed all
212 cases.

The final live gate regression failed before the service root was wired in.
Afterward, the late-audit, LAC-2331 and Hammer range suites passed all 128
cases (`node --test test/hamlateaudit-01.test.mjs test/lac-2331.test.mjs
test/hammer-head-validation.test.mjs`).

The Hammer predicate's full issue timeline now counts only comment events
toward the attestation cap. A regression covers more than 1,000 unrelated
timeline events alongside a valid App comment.

The first independent review found that the final Hammer shell gate still
omitted the runtime root. The rendered-gate regression now proves that a
changed review on the pre-round head refuses merge after validation. The
follow-up filters unrelated timeline events out of the comment bound, skips
completed-job scans for proven snapshot comment chains, reports scan limits,
requires an explicit checkout for diagnostic patch proof, and documents the
independence of exact attestation when GitHub comparison is unavailable.
Both hosted jobs passed on the reviewed head. The post-review offline run
passed all 208 selected cases, plus lint, contract typecheck and the offline
walkthrough.

Agent OS PR #11475 exposed a related gap before Hammer publication. Its
completed local Comment-only round already recorded a verified job-bound
Git replay from `eaa1f132` to `4688855e`. The daemon used that record for
handoff, while review selection and the Hammer starting-range check missed
the replay. Both now accept the exact recorded publication. The source
review remains subject to supersession, and the publication alone never
waives exact-head merge validation.
The follow-up passed 176 selected offline tests, lint, contract typecheck and
the byte-equivalence walkthrough. A read-only check against the protected
completed-job record for PR #11475 confirmed the exact endpoints.
The full local run reached its deadline with 824 files queued. Its
watcher fixture omitted the new replay reader export, and six Hammer
fixtures hit their subprocess timeouts. After adjusting the watcher fixture,
the focused watcher and currency rerun passed 231 cases and the two
Hammer rebase shards passed 51 cases.
