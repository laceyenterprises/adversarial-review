NXA-02: pure shared next action with an observational shadow at every closure consumer (pr-next-action@c216a174c80e)

Add nextAction(snapshot): a pure, total successor to decideClosureOwner
that reads one NXA-01 pass snapshot and returns exactly one
{action, actor, reason, deadline, head, round?, evidenceRefs, decisionKey}
from the ordered spec table. Unknown evidence never falls through to a
more permissive row; drain/capacity apply once after selection.

Legacy decideClosureOwner keeps authority and every effect. An
import-free consumer seam copies evidence synchronously and lazily runs
the shadow at closure orchestration, posted-review, the no-progress lane,
the closer handoff, the rescue classifier, the hammer-owner route and the
watcher handoff wake. All consumers of a pass share one decision.
Disagreements and overdue decisions go to a bounded local JSONL log;
overdue alerts use the closure-wait path only with
AMA_NEXT_ACTION_OVERDUE_ALERTS=1. bin/next-action-disagreements.mjs
classifies live cases read-only for the rollout owner.

No caller switch, CI check, gate, config key, lifecycle state or state
projection change.
