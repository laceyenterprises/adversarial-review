# LAC-2354 — Preserve review currency across context-only rebases

## Summary

Compare the PR's ordered commit deltas at their original paths and modes.
When the base changed a regular file, Git must replay the edit cleanly in both
directions and reproduce the exact blobs. Empty commits retain their positions.

Native final-fix-all recovery uses the original repair reservation and its
verified source. When a completed remediation round moved the source past the
reviewed head, the reader checks the original round publication and replays its
parent. The source series must then replay as the live prefix. Each extra
commit needs its own signed native publication for that branch, launch, and
worker. This evidence carries findings for fresh adjudication at the live head.

## Interface changes

Clean local rebase proof reports `reviewed-rebase-replay`. Existing consumers
recognize the historical `reviewed-rebase-patch-id` value. A custom Git executor
must support byte output for `merge-file` when `options.encoding` is `buffer`.
