existing mocked clock and a child-start checkpoint. Strengthen the separate
operator admission-timeout fixture to prove zero child attempts and signal
cancellation. See the [SEV report](../postmortems/SEV3-inventory-timeout-fixture-raced-admission-LAC-2191.md).

completion, surfacing setup rejections and recorded pre-dispatch errors without
waiting for the runner deadline. The mock child rejects with `AbortError` on
cancellation, and the fixture asserts that rejection.
