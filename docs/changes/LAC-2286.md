ref-addressed lookup. PR metadata, reviews and owner and publication evidence
retain their live reads.

Wall times cover collection and verdict, including local Git processes, under
different levels of test-runner contention. The endpoint counts measure
request savings. These wall times establish no live latency improvement. The
primary-change suites also exercise linked and foreign committers, verified and
unsigned web-flow commits, and missing or SHA-mismatched verification.

Source publication, deployment and incident acceptance are separate. The
operator owns fleet capacity decisions. Per-consumer request counts on the
native shared quota across a reset window are needed to distinguish scheduled
history demand from other consumers before assigning a capacity remedy.
Incident acceptance requires fresh exact-head source verdicts through the
native route after admission, with root retaining the two Agent OS PRs.
