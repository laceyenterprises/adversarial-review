# Preserve closer validation custody and audit diagnostics

## Summary

The early validation-deferral audit checks custody at its resolved head as
well as the validation remote and dispatch heads. A custody record that
requires operator action produces a `park` continuation even when another
candidate has a clean hold.

When the watcher reconciles an ended validation deferral, the appended `park`
attempt retains the diagnostic reason detail and overload evidence from the
prior attempt.

## Interface changes

The latest validation-deferral attempt retains the existing optional
`reasonDetail` and `overloadEvidence` fields through reconciliation.
