# LAC-2441 — Bound native remediation publication

## Summary

The native publisher uses a live supervisor to own each command's dedicated
process group. A deadline, cancellation or output overflow sends SIGTERM and
preserves SIGKILL escalation even if the command exits and its descendants
close their capture pipes. Ordinary exit sweeps remaining group members.
The CLI and routed credential recovery both use the managed runner. Native
pushes reserve the strict 45-second measured pre-push tier in addition to the
load-aware transport deadline. A fast-check failure blocks push, and hosted
required checks gate merge.

## Interface changes

The publisher verifies the exact remote branch ref after a successful push
command. Transient read failures allow two retries within the original
load-aware read budget. Authentication and access failures stop verification
with specific diagnostics. Interrupted pushes, unreadable refs and
mismatched refs use `remediation-publication-unproven`. Recovery checks the
live destination before another write because the remote may have accepted
the update. The selected owner route retains its broker-issued grant and
credential checks.

## Verification

In five Node 22 runs on the reviewed source, both process-group regressions
failed each time. Exit cleanup issued a numeric group signal after leader
exit, and cancellation cut short the armed TERM grace. After the fix, each
regression passed in all five runs of `test/process-group-spawn.test.mjs`.

The Node 22 hosted `assert-launch` shell fixture spent simulated controller
time while waiting for the gate request, then charged the gate's retry
backoff to the same clock. The fixture now grants controlled poll time for
the fresh and stale observations, advances through the real gate backoff
values and counts only reads while the gate request is active.

The scoped `npm test -- <test files>` run covered the process runner, hammer
controller, publication checks, owner routing, credential reminting and
workflow recovery. It passed 314 tests with one platform skip. Lint, contract
typecheck and the offline research-finding walkthrough passed.
