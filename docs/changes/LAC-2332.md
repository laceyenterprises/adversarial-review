# LAC-2332 — Keep deferred closer source across launches

## Summary

The protected dispatch output for Agent OS #11457 showed local repair
`2e39641a682080d6ac000f51673ea380bee26cfb` and a child-check timeout. On #11470,
a closer rebased to `ea1c4783e73817ebba6ec13fd419cfd20339c1cf`; its successor
rebased the same live head `733bbe56f690ce2df00765334aa5a478fd39a861` to
`6ef35acdd04b47fb82e93d9846f5171a431c6314`. Both stopped before publication.
The three bounded-runner receipts recorded status 124 and `cleanup=finished`.
The last launch's printed deferral receipt explicitly recorded UNKNOWN for
`6ef35acdd…`. The run-local check files named in the logs were no longer readable
at those paths. A fourth closer started from the same live head.

## Interface changes

A canonical deferral now holds the exact target and preserves the original
commit, check identity and cleanup receipts beyond run scratch. The watcher
keeps infrastructure refunds and asks for one same-head operator decision
instead of dispatching identical work. A standalone UNKNOWN can defer to GitHub
only with a proved full check selection, local passes for all checks without
authenticated coverage, and confirmed cleanup. The live required CI, source,
review and lease gates still apply. A controller stop never launches a fresh
round.

## Verification

The offline regression uses two distinct launch IDs and checkouts. Against the
trunk validator, the broad check runs twice and the unpublished commit has no
custody record. With the repair, the test removes the first checkout and
scratch, recovers the exact commit from the retained bundle, and verifies the
second launch runs no battery. Separate fixtures cover failed or unfinished
local guards, unconfirmed cleanup, and the watcher's once-per-head notice.

Repository validation used `node test/run-tests.mjs` with the scoped closer
files, `npm run lint`, `npm run typecheck:contracts`,
`bash demo/research-finding-walkthrough.sh`, catalog validation and diff checks.

After normal deployment, separately observe a newly loaded revision produce an
organic deferral, retain its source and cleanup receipts, and verify the watcher
withholds a same-head successor. Source publication and required GitHub CI are
separate from that observation.
