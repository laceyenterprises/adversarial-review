## Interface changes

A canonical deferral now holds the exact target and preserves the original
commit, check identity and cleanup receipts beyond run scratch. The watcher
keeps infrastructure refunds and asks for one same-head operator decision
instead of dispatching identical work. A standalone UNKNOWN can defer to GitHub
only with a proved full check selection, local passes for all checks without
authenticated coverage, and confirmed cleanup. The live required CI, source,
review and lease gates still apply. A controller stop never launches a fresh
round.
Final comment-only remediation retires proved standalone CI holds with an
archived `continuedAt` marker and CI-authoritative phase receipt. Teardown
matches custody by launch across all PR target heads, retaining unbundled
source after an earlier publication. Changed source/cleanup evidence refreshes
notices, corrupt legacy retry evidence holds, and SIGKILL gets a bounded
one-second drain window. Runtime-owner same-head release still requires both
records; a combined release tool and host-scoped fault paging remain follow-ups.
Existing PR-head CI also exposed stale expectations for automatic retries after
canonical deferral, old prompt wording and state projections. The fixtures now
require the source-decision hold and refund, match the current no-retry/receipt
contract, and refresh reviewed source projections without changing the lifecycle
graph or CI configuration.

## Verification

The offline regression uses two distinct launch IDs and checkouts. Against the
trunk validator, the broad check runs twice and the unpublished commit has no
custody record. With the repair, the test removes the first checkout and
scratch, recovers the exact commit from the retained bundle, and verifies the
second launch runs no battery. Separate fixtures cover failed or unfinished
local guards, unconfirmed cleanup, and the watcher's once-per-head notice.

Repository validation used `node test/run-tests.mjs` with the scoped closer
files, `npm run lint`, `npm run typecheck:contracts`,
`bash demo/research-finding-walkthrough.sh`, catalog validation and diff checks.
Final remediation passed 41 focused cases through the isolated runner: 23
custody/inconclusive cases, nine cleanup/signal cases, four state/prompt contract
cases, the qualifying UNKNOWN-to-merge case, the canonical-refund hold case and
three watcher claim cases. `NODE_OPTIONS=--test-name-pattern=...` selected the
affected cases in larger files, including their filenames for runner admission.
Broader scoped-file attempts exceeded their local bounds; they do not establish
full-file success. The full suite remains the PR-head CI gate. Lint returned
zero errors (147 existing warnings); contracts, walkthrough, catalog and diff
checks passed. The UNKNOWN fixture has a bounded 60-second standalone allowance
to include startup and receipt retention on contended hosts.

HAM traced both hosted Node failures to six extra SQLite reads in the
posted-review fixture. Reason changes now reset the page reservation in the
existing update, preserving notice refresh and the watcher read budget.

After normal deployment, separately observe a newly loaded revision produce an
organic deferral, retain its source and cleanup receipts, and verify the watcher
withholds a same-head successor. Source publication and required GitHub CI are
separate from that observation.
