# LAC-2319 — Close the final PR 2005 advisories

## Summary

- Codex credential and HQ executable discovery use the OS account record when
  `HOME` is unset, empty or relative. Per-worker auth, alert configuration and
  transcript discovery use the same absolute-home rule. An unresolved account
  provides no implicit path. Explicit operator paths retain their precedence.
- Closer HQ resolution accepts null and primitive environment values. Deployment
  root resolution returns canonical absolute paths from both supported sources.
- The remediation workspace guard recognizes the vendored service path even
  when config loading fails. The guard rejects roots under live source and
  the deploy checkout through symlink aliases and preserves isolated local scratch.
- The rejection fixture advances a deterministic clock. The watcher fixture's
  diagnostic flush patch registers cleanup before installation and refuses
  nested registration.

## Interface changes

Relocated deployments retain their default transcript fallback. For six Claude
lookups over 24 projects with four transcripts each, the offline fixture
recorded 150 directory listings and 576 JSONL reads. The isolated worker lookup
performed zero listings and reads by default. The completion reader still
scans fresh so appends, rewrites and newly competing session matches remain
visible. The existing per-backfill cache has a call-scoped lifetime and cannot
reuse these listings across worker completions. The fixture measures the scan
scope. Production volume remains unknown.
