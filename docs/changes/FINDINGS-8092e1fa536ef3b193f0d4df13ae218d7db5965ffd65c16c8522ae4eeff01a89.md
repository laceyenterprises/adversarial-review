# Keep the capped merge lease polling test isolated from host PIDs

## Summary

The test recognizes the simulated holder's `ps` start-time lookup in either
argument order and asserts that CLI polling uses the mocked timestamp. The
fixture's setup calls cannot satisfy the polling assertion.

## Interface changes

None.

  born after lease acquisition. The original capped-polling test reclaimed at
  0 ms. The updated test reclaimed at the expected 45,750 ms, and all 64 tests
  passed in `npm test -- test/ama-merge-lease-cli.test.mjs` with the loader.
- `npm run lint` completed with zero errors and 149 warnings.
- `npm run typecheck:contracts` passed.
- `bash demo/research-finding-walkthrough.sh` produced three byte-stable
  deliveries.
- `npm test` reported a sandbox smoke timeout and reached the runner's
  900-second limit. The sandbox smoke hit its `clean` step time limit on
  the worker checkout. All 11 smoke tests passed in a temporary copy of
  the repository both before and after applying the fix.
