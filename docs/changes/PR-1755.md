# PR-1755 — Repository discovery exclusions and fallback diagnostics

## Summary

Static-only discovery resolves retained rename identities before applying the
same case-insensitive short/full-name exclusions as organization discovery.
Startup fallback warns for every non-excluded static or known candidate omitted
by persisted quarantine or ambiguous ownership history. Busy startup listings
explain why new repositories must wait for safe reconciliation.

Moved the three discovery regressions from `src/` into the existing collected
`test/watcher-repository-discovery.test.mjs` suite and added coverage for renamed
static exclusions and historical ambiguity affecting static-only candidates.

## Interface changes

None. No persistent schema, lifecycle state, smoke promise or CI configuration
changes. The repository identity contract now describes canonicalization and
fallback omission diagnostics explicitly.
