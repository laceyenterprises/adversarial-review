# PR-1963

## Summary

Reviewer snapshots for clone-root repositories now stay outside the review
service checkout and its detected superproject when the review ledger uses the
default service-local `data/` directory.

## Interface changes

`prepareReviewerWorkspace` accepts the service checkout directory so its
workspace-state selection can exclude all source worktrees. The reviewer passes
its own root. Explicit workspace-state overrides inside those worktrees fail
closed.

## Verification

`node --test test/reviewer-workspace.test.mjs` passed 41 tests, covering
clone-root snapshots with the default service-local state directory and the
unsafe override. `npm run lint` passed with zero errors, and
`npm run typecheck:contracts` passed.
