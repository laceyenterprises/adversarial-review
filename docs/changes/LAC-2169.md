repository classifier. A readable foreign registry leaves conflicts on the
explicit source-repair path, including paths that share a name with a foreign
generated output. Missing or unreadable ownership refuses continuation and

replay needs additional source resolution. On completion it still runs the
reviewed-head preservation proof and writes the head-bound publication evidence.

nested Git invocation, preserving Markdown headings in author messages.
