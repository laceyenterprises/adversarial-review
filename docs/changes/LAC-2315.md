## Interface changes

The completed follow-up round now supplies exact-head review intent when it
contains a validated, complete evidentiary dispute of the current blocking
review. The existing orphan watchdog admits the cross-model review once per
head. It writes an explicit intent so the existing same-head GitHub review
deduplication can distinguish this request. It preserves review counters and
checks that the posted row still matches before queueing. Live review, worker
and lease custody retain priority.
The existing review ceiling routes to hammer adjudication. Failed review
admission escalates once through the bounded operator page, which identifies
the head and retained job reference.

Worker evidence remains in the reply and corpus. Historical worker withdrawal
rows and new worker replies confer no withdrawal authority in the status gate,
AMA eligibility or GitHub review dismissal. Authentic hammer dispositions
continue through those consumers. Settled Comment-only fixes retain their
normal finalization path.

[LAC-2307](https://github.com/laceyenterprises/adversarial-review/pull/2009)
owns classification and closure of protected-pack deferrals. This change reads
the kernel validator's normalized reply and requires a completion with
evidence for every blocker. Operator-owned blockers from that validator
continue through the protected-pack handoff. The remediator prompt has separate
rules for protected-pack edits and factual disputes.
