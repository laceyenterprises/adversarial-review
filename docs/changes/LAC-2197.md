# LAC-2197 — Keep HQ cancellation after local closer retirement

## Summary

Adversarial Review #1895 closed while its closer was still admitted with no
worker process. The watcher deferred #1896 behind that closer. The follow-up
reaper settled the local #1895 lease, and HQ continued to count its launch.
A confirmed operator cancellation retired it in place.

The closed-PR queue previously depended on finding a live local lease for
every retry. Retiring the lease therefore made the next attempt delete the
obligation before HQ confirmed cancellation. The queue now carries the
observed launch ID when available and can recover earlier records from the
original head. Only terminal HQ evidence can settle an outstanding launch,
and local completion is fenced against a replacement.

Final review remediation makes pending-lease age and property reads explicitly
safe when the local lease is absent. Cancellation still uses the queued launch
ID after the lease file is deleted.

## Interface changes

Cancel obligation records can carry a nullable `launchRequestId`. Older
records remain readable. The HQ cancellation audit uses
`obsolete-closer-pr-closed` for this path.

a nonterminal HQ result and settles after confirmed cancellation. A second
regression verifies that a same-head replacement keeps its custody.
