# LAC-2243 — Patch minimatch in the ESLint dependency chain

## Summary

Raise the ESLint development dependency floor to `^10.15.0`. ESLint 10.15.0
requires `@eslint/config-array` `^0.23.6`, and both packages require minimatch
`^11.0.5`. The lockfile resolves them to ESLint 10.15.0, config-array 0.23.6
and a shared minimatch 11.0.9. The first patched minimatch release for
[GHSA-g3hv-75wg-m249 (CVE-2026-118764)](https://github.com/advisories/GHSA-g3hv-75wg-m249)
is 11.0.1.

## Interface changes

None.

## Verification

- `npm audit` reported three moderate entries in this chain before the update
  and zero vulnerabilities after a clean `npm ci --no-audit --no-fund`.
  `npm ls eslint @eslint/config-array minimatch` confirmed both consumers
  use minimatch 11.0.9.
- `npm run lint` passed with zero errors. `npm run typecheck:contracts` and
  `bash demo/research-finding-walkthrough.sh` passed, with three byte-stable
  transcript deliveries.
