# LAC-2093 — Canonical HAM validation evidence and cleanup

## Summary

Retain bounded command output as canonical CI-mirror checks run and keep the
mirror's timed commands within the controller's owned process group. A check
deadline stops validation and requests bounded, ownership-fenced teardown.

## Interface changes

Private validation receipts can carry `checks[].diagnostics` entries for
bounded output files beside the receipt. Standalone runs print the private
receipt location. For a registered validator, `cleanup=controller-owned`
identifies a stop request. The final controller registration reports drain.

Explicit mirror failures (exit 42 or a per-check `fail`) take precedence over
the canonical own-package import-fault environment fallback, including a battery
whose only failure is an own-package import error. Other canonical setup faults
still defer to exact-head GitHub required checks without claiming a local pass.

The shell-runner replacement checks the known keyword-only signature before
installation; incompatible runners keep their original function with a warning.
Supported mirrors run checks sequentially and combine stderr into stdout.
Read-only inspection of Agent OS at `2c6e15e23ea7ab1a50004d765bfde6a1755233fd`,
`scripts/ci-mirror/run-ci-mirror.py` (`run_shell_command`, `_run_check`,
`run_checks`) confirmed the signature, `stderr=None`, sequential loop and absence
of a `BaseException` catcher. Offline fixtures pin the annotated production
signature and incompatible shapes without depending on that checkout.

Failed/interrupted evidence has caller-owned retention through diagnosis and
confirmed process drain, then is removed with its private run/evidence directory.
The runbook and both catalog records now name standalone evidence directories
and per-command logs. There is no automatic expiry or aggregate byte cap.
Real-census controller fixtures now run sequentially with shorter check/validator
deadlines and six-second finite descendant lifetimes.

  exercises the actual process census, retained logs, timeout, cancellation
  and fenced lease release in disposable fixtures. The baseline lost both
  logs and left two check processes outside the controller group in all
  three concurrent rounds. Three repaired batches passed all nine concurrent
  outer-timeout rounds, three inner deadlines and three launch cancellations.
  The standalone fixture passed in each batch with a real failure and a
  truncated 4 MiB diagnostic.
- `npm run lint`, `npm run typecheck:contracts`, `bash demo/research-finding-walkthrough.sh`

  `test/hammer-ci-mirror-validation.test.mjs` and `test/hammer-controller.test.mjs`
  passed in 24.4 seconds, covering the runner contract, sequential timeout/drain,
  cancellation, output limits and import-only failures with both receipt modes.
  The signature tests passed again after formatting; all fifteen
  `test/hamselferrors-01.test.mjs` cases passed, preserving the unsupported-mirror
  environment fallback. Lint (zero errors), contract types, the data-model catalog
  validator, Ruff check/format, the offline demo and `git diff --check` passed.
  The full local suite was not run; exact-head CI remains the merge gate.
