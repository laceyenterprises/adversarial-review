The reader formerly requested the same recursive tree separately for each
commit SHA that named it. It now uses the canonical Git tree SHA from each
independent nonrecursive root response. Each snapshot still checks its root
entries and verifies the descendant tree SHAs. GitHub can return an explicitly
truncated response, in which case the original subtree walker still runs.
Existing checkpoints that lack the optional tree SHA retain the original
ref-addressed lookup. PR metadata, reviews and owner and publication evidence
retain their live reads.

The final remediation documents that checkpoint key aliases may cover only
optional fields whose absence the reader tolerates. Default shared-tree tests
use 53 paths; the 353-path measurements require explicit local opt-in. The
wall-time comparison was removed because its runs had different contention.

The old collector built and discarded the 25-path snapshot before rebuilding
all 995 projected patches. With a cold reader and complete recursive trees,
the three snapshots imply 1,740 distinct blob lookups and 1,038 file diff jobs
before optional proof work. The scoped reader keeps all 995 inventory rows
and needs 449 distinct blob lookups and 258 diff jobs in those same snapshot
phases, including 240 projected patches. These are object-derived work counts,
excluding cache hits, retries, later proof reads and branch movement.

`npm test -- history-merged-main-budget.test.mjs` replays a public, synthetic
Git graph with hashed commits, trees and blobs and real Git hunks. Each API call
charges 80 ms and each diff charges 20 ms against an identical 90,000 ms
context budget. The legacy path times out at the 90-second boundary (one
observed run reached 988 calls and 550 diff attempts at 90,040 simulated ms
while in-flight work settled). The scoped path completes with 273 API calls
(five compare, six tree, 261 blob and one live PR read) and 261 diff jobs in
27,060 simulated ms. The model tests budget consumption and is independent of
native endpoint latency. It also refuses a reverted author migration, an
incomplete recursive tree and a missing commit page. The guard baseline read
uses inventory only, and the migration repair tests verify intermediate
snapshots and operation bytes without reconstructing their patches. The exact
affected head still requires a fresh root-owned native proof after the source
fix lands.
