# Hammer stop-origin registry simplification

## Summary

Remove the redundant `hammer-command-error` override in the stop-origin registry.
The registry still classifies command construction errors as closer faults and
retains the reason in the legacy infrastructure set.

The final advisory remediation adds an isolated regression test that loads the
registry with `hammer-command-error` removed from the legacy infrastructure set.
Its existing explicit property still registers the reason as a closer fault,
including in `HAMMER_CLOSER_FAULTS`; registration does not depend on that set.

None.
