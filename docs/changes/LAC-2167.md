# LAC-2167 — bounded primary-change verification (HAMHISTORYBUDGET-01)

## Summary

The reported operator merge of Agent OS #10268 at
`4e82bfaa39031da9febb10e565016bef8b0ddb0d` exceeded 180 seconds; its
read-only repeat reportedly remained undecided after 275 seconds despite green
hosted checks. No live reproduction, mutation of #10268 or deployed-file modification
was performed. Offline stalled injected transports confirm a shared source
defect: the history deadline was checked only between operations, and the
complete collector had no independent deadline. Quota admission, authentication,
cache waits, ignored cancellation and optional proofs could outlive that limit.

The complete collector now returns classified retryable timeout evidence within
a fixed 90-second wall-clock budget. Per-attempt waits can scale with host load,
but the total limit cannot. Real history commands own cancellable process groups;
tree/blob/diff work shares cancellation and diff scratch is removed after workers
settle. Late injected results cannot continue collection.

Native closer calls retain their shared quota scope and immutable-cache reuse
after a shorter tick expires, within the independent verification bound.
Standalone/rescue-shaped reader calls use a defer-on-quota scope. The external
180-second rescue supervisor is distinct from the shared verifier. These
fixtures isolate shared behavior; they do not identify the precise deployed
rescue transport responsible for the reported live stall.

The in-lease failure fixture verifies release, no merge and successful retry at
the same exact head. Strict primary preservation, authoritative finding reversal
proof and exact-head checks remain required. No configuration, lifecycle state,
CI job, deployment or live recovery action is added.

## Interface changes

`fetchPrimaryChange` returns `historyReadTimedOut: true` alongside existing
`historyReadFailed` / `readFailed` fields on a context deadline. The existing predicate
classifies this as `history-read-failed`. Readers expose `withSignal(signal)` for
per-collection cancellation. Tests can shorten `contextTimeoutMs`; production
defaults to 90,000 milliseconds.
