# LAC-2335 ROUNDCURRENCYBOUNDS-01

## Summary

Addresses the completed-round bounds, capped-comment diagnostics and mixed-chain
head-match finding from Claude's post-merge review of [#2029][review].

Completed proof scans stream filenames in the existing shared directory.
Unrelated jobs consume no record or edge budget, but the whole directory scan
stops after 125,000 entries. Limit warnings identify the
repository, PR and limit and recur at most hourly while their key is cached.
The protected job records and authenticated Hammer comments remain in place.

A completed non-final round followed by an authenticated Hammer push can
still keep findings and later reviews applicable. The mixed chain can waive
the head match only if each native edge has a proven, exact comment-only final
handoff with re-review suppressed. Hammer range evidence remains available to
validate responsibility. The later review, operator veto, source, exact-head
CI and ownership checks still govern closure.

## Interface changes

`hammer-provenance-comments-capped` identifies an exhausted comment proof in
stale-head and review-currency diagnostics. Terminal review validation and
review citation checks refuse to treat a review as inapplicable when a cap
prevented proof and that review could affect the result. An older diverged
review cannot supersede an exact-head cited review. An independent proof can
still establish applicability. `pr-blockers` reports each distinct proof limit
once per row. The protected completion writer's descendant push record is
accepted by the handoff reader.

LAC-2334 owns review reopening and routing for affected heads. Its owner can
use the retained stale-head refusal after a pending non-final review followed
by a Hammer push as a regression case. LAC-2330 and [#2021][ci] own the
integrated CI fixture and config-cache repairs that traveled with #2029.

The Hammer closeout documented the shared directory ceiling in the completed-job
data model and the HAM starting-base lookup runbook.

The final remediation resolves copied reviews to the canonical review by ID and
commit before checking supersession. Both completed-handoff helpers return
`null` for missing or non-object inputs. The data model documents the explicit
published head required for standalone local replay.

It exercises the shared currency reader, stale-head predicate and AMA
eligibility. The positive cases cover a settled final handoff, exact Hammer
provenance and the existing one-job comment-only convergence. Additional
fixtures cover per-target overflow, capped snapshots and pagination, and a
later review whose applicability is uncertain when comment proof is capped.

`npm run typecheck:contracts` passed and `bash demo/research-finding-walkthrough.sh`

passed 40 tests. After updating the daemon terminal-audit fixture to cover both
handoff outcomes, `node --test test/daemon-ham-terminal-remediation-remerge.test.mjs`
passed 16 tests.

the completion writer's descendant handoff. The three targeted files passed

comparison. A review proven inapplicable needs no head-to-head comparison,

cited review.

The final Hammer validation passed 615 targeted tests across 27 files, including
