again under the lease. A hold that appears during acquisition keeps the
lease release charge. Later held passes skip the gate and audit and pace
remote identity probes. The live branch lookup can fall back to GitHub's
branch endpoint within the same read budget.

A proof timeout or unclassified preflight refusal with verified
non-invocation settles the intent and allows ordinary bounded redrive
with the launch and lease charges intact. A
transient confirmation failure after an already-merged observation uses
the existing accepted-confirmation deferral. GraphQL integration and
write or admin access refusals can produce a permanent refusal, including
after a definitive credential rejection and refresh. A later refusal
retains reconciliation custody if an earlier click remains ambiguous.

The in-run retry remains bounded by the existing deadline and lease. It
recovers transient transport errors and stale credentials after fresh
head, base, gate and review checks. Retiring the legacy repair fences or
migrating the writer to queue authority would change recovery ownership
outside this remediation. The operator reconciliation command remains in
the closure runbook.
