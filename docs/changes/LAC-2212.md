## Final comment-only remediation

whitespace or end of text, while longer extensions and path components remain
refused. EOF-only insertions use the last original source line for finding
coverage; out-of-range insertions and missing coverage still fail closed.
The closure runbook documents both boundaries. No public interface, persisted
shape, lifecycle state or smoke promise changes.
