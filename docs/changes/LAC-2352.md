# LAC-2352 — First-review routing and quota probe settlement

## Summary

The incident owner observed Agent OS PR #11586 at head
`db4a9e3406935b499ec4d58201f9d810ba9163d3`. Discovery preferred Gemini through
`always-on-third-reviewer`. Admission tried Claude, whose Anthropic quota
probe errored. Session `5d483731-ee51-4359-9638-cd682413d5d1` had no reviewer
PID or artifact. Settlement used the no-reset quota-exhaustion path and
logged a hold until 23:55:50Z. The same observation window showed Gemini
reviewer PID 41027 and AGY PID 85286 for Agent OS PR #11585. That establishes
execution for #11585 at the time observed.

The watcher first computes the route through the Gemini, Grok, AFH and
retry layers. Its pool can then intentionally reselect a worker class as
wait or depth pressure is evaluated in admission order. The claim CAS stamps
that final reviewer and session, and preflight uses the selected bot and
account. The original Gemini message described only the discovery preference.
The incident evidence identifies the route change, and the offline replay
exercises the maximum-wait trigger through the production pool.
The spawn guard kept Claude held on the unreadable probe as required by the
credit-spend policy, but returned `quota-exhausted`. The generic quota
settlement then logged the missing reset and applied the default quota hold
in the absence of any exhausted-provider evidence.

The watcher checks a wait, depth or burst spill's selected credit-capable
account before charging the spill. An unreadable probe can use the existing
AFH fallback order before the pool rechecks capacity for the returned route.
The final launch preflight still checks the actual selected account. A late
probe refusal journals a skipped pass and releases the matching unstarted
claim on ordinary cascade backoff. Claim and runtime logs distinguish the
preferred, admitted and invoked reviewer. A runtime receipt or process
evidence establishes execution. Skipped probe refusals preserve the hard
review-attempt ceiling.

Launch-time probe refusals release the admitted pool slot as undispatched and
refund a reserved spill once. Successful settlement commits the spill even if
the runtime adapter omits its process-start callback.

## Interface changes

Watcher logs distinguish `reviewer-preference` from `reviewer-route-admitted`.
The latter carries exact head and session. Skipped quota probe refusals use
`quota-probe-unavailable` in the existing pass metadata and cascade records.
Existing genuine quota and credential protections still apply.
