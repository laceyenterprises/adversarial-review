# LAC-2278

## Summary

The native primary-change proof at Agent OS PR #11274 head
`3ac6fe711e9c4d909d0408ed6575c35bae18cf66` returned `snapshot-body-mismatch`.
The snapshot reader parsed `successful_rss_index_339` as a filename slot and
looked for the declared revision in slot 339. The applied wrapper and helper
are in slot 340. The earlier RSS integration certificate handles a child
moving out of slot 340 and did not apply to this slot 341 collision.

The native collector selected protected head `4ce0c4fd175a29f6bffd903b52d7dbf7dac1da2f`,
old base `c1342ec7d877292aaa77d0256d3a604320cf9a24`, and comparison base
`f408236ecde248c63ecfb5fbe75f2f159f2ac7e9`. The check covered the intervening
head `af8a702baae722ec89dccb6d2eb5e3179aa4bb88` and the final two-parent
integration. The wrapper and module change their own revision from
`dag_slice_history_index_341` to `dag_slice_history_index_342` and switch
their predecessor to `operator_completion_reason_341`. The index SQL blob
is `b04e5cedabda3285e453a16e1991d87ede208615` on both heads.
[Exact Agent OS source comparison](https://github.com/laceyenterprises/agent-os/compare/4ce0c4fd175a29f6bffd903b52d7dbf7dac1da2f...3ac6fe711e9c4d909d0408ed6575c35bae18cf66)

The checker now requires a complete immutable ledger proof for this split.
The fixed native local evaluation recognizes only the proved preservation
paths on the same evidence object and exact head.

## Interface changes

The transient `mainIntegration` proof can include a `historicalParent`
binding. Failed checks in this path can report
`historical-parent-snapshot-unproven`.
