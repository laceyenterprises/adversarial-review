# GEMREMEDIATORCLASS-01

Gemini remediation normalizes concrete fallback configuration to its logical
route and translates only HQ remediation dispatch to `remediator-gemini`.
Pooled refusal ordering now includes Gemini through ordinary model/quota
selection. Native/SDK receipts preserve logical attribution and stable round
identity. Local agy, broker/Git identity and remote-proof fences are retained.

Pooled routing attributes an unpooled candidate with no resolver result to
`skipped[]` as `unpooled-fallback-unresolved`, then continues in declared order.
Offline regressions cover missing, null and undefined resolver results, both
with no remaining route and with a subsequent successful pooled fallback.

See the [SEV/RCA and paired release prerequisites](../../docs/INCIDENT-2026-11-02-gemini-remediation-builder-class.md).
