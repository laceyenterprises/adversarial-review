# LAC-2175 — HAMCENSUSEIO-01

## Summary

Reproduce the native Agent OS #10379 (`baff9543c66c`) pre-lease census failure
with an offline injected `kern.proc.pgrp` syscall returning EIO. Retry only
explicit EIO/EINTR syscall failures with fresh buffers and 10/20ms spacing,
bounded to three interruptions per request across buffer growth. Keep the
existing deadline, completeness, birth/PID/PGID and zombie checks. Unknown
evidence never becomes an empty group or authority to acquire a lease.

## Interface changes

Exhausted interruptions retain their errno and add `retryable: true` and
`censusAttempts: 3` to adapter errors; definitive refusals have
`retryable: false`. The helper carries this distinction over both serve and
one-shot protocols. No config, durable state, controller lifecycle, merge
authority or smoke promise changes. No production processes, live config or
custody of #10379 are involved.
