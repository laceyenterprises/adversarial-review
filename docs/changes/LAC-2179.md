# LAC-2179 — CLOSERRECEIPTIDENTITY-01

## Summary

Add supported, audited recovery of an older exact-key closer receipt that never
stored a ticket. Receipt recovery preserves launch identity and attempt accounting;
ordinary terminal reconciliation releases its reservation for follow-up admission.
No live state or incident PR is changed.

## Interface changes

The owner-only legacy settlement command additionally returns `receipt-recovered`
for a proven ticketless terminal launch and audits `settled-terminal-receipt` (or `receipt-adopted-settlement-pending` while observation is unknown).
See [proof requirements and deployment dependency](../dispatch-absence-recovery.md#ticketless-historical-receipts-closerreceiptidentity-01).
The companion [agent-os PR #10561](https://github.com/laceyenterprises/agent-os/pull/10561)
projects stored `worker_class` and additive producer `ticket_identity` evidence;
the pinned SDK transports it unchanged. Existing no-launch recovery is unchanged.
