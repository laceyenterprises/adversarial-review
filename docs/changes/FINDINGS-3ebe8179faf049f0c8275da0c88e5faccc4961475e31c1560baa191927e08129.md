# Preserve docs waiver withdrawals while review is queued

## Summary

During a watcher drain, an unrouted docs-only PR can remain queued for review
after a settled failure withdraws its waiver. Preserve the pending withdrawal
when projecting the queued status for the same head. Later polls keep the PR on
the ordinary review path, and assigning a reviewer restores normal status
projection.

## Interface changes

None.
