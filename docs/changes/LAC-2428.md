# LAC-2428 | Retire a fenced CWP reservation at its unchanged head

## Summary

AR can retire an unscoped, `absent-unfenced` CWP conflict reservation
at its unchanged open PR head after confirmed HQ apply commits the exact
owner and epoch fences. The read-only consumer matches both committed
receipts and refreshes PR and reservation evidence under the existing
PR locks. Retirement retains the original epoch, spend, cap usage and
prepared source. Future work requires separate authorization and ordinary
review and CI.

## Interface changes

The pinned LAC-2427 HQ producer calls
`inspectSameHeadRepairRetirement(root, evidence)` before issuing apply
confirmation and again during apply. The probe checks exact AR custody
under the existing locks. AR retirement accepts equal `--base-head` and
`--current-head` only with `--ledger-absence`. The receipt reader refuses
an older HQ producer as `same-head-fence-producer-unsupported`.
[Pinned producer](https://github.com/laceyenterprises/agent-os/tree/af598a83b393304f672a0476f30604a17979cba9)

The HQ and AR owners handle production readback separately after compatible
deployment and operator authorization.
[Runbook](../RUNBOOK-ama-closure.md#unchanged-head-cwp-reservation-lac-2428)

Deploy HQ LAC-2427 before or together with this AR change for **all**
retirement variants, including legacy in-place and moved-head CWP. All
read-only receipt reads require `_check_scope(..., readonly_connection=True)`.
Older HQ builds can produce the generic evidence-unavailable refusal.

The same-head private-helper check remains a pinned producer build marker;
it is not a public protocol version. The reader now reuses the imported
module. Requiring a public capability is deferred to a coordinated HQ producer
change; no producer or superproject documentation is edited in this AR round.
Fresh committed-receipt/evidence equality remains the behavioral check.

Watcher intent try-lock contention defers observation without writing or
resetting absence evidence. Actual read failures still reset unscoped CWP
evidence. The readiness probe now reports `repair-ledger-unavailable` for a
missing/corrupt ledger, separately from reservation mismatch.
