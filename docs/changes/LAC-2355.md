# LAC-2355 — Account for a completed follow-up in source authority

## Summary

The primary-change gate can account for one verified documentation-only final
follow-up between an exactly replayed review and its first HAM repair. The
proof pins the review, base, commit parents, worker publication and complete
file deltas. Missing or inconsistent evidence preserves the refusal.
Transient publication reads use the existing retryable history-read hold.
Malformed optional tree evidence leaves the main reader and its progress intact.

## Interface changes

No caller or configuration changes. The proof is evaluated from live review
and publication evidence and immutable Git objects. The worker App lookup
uses the reader's environment. Strict finding coverage and removal-content
checks still apply.

## Verification

The incident replay moved from `reviewed-parent-patch-differs` to
`not-covered-by-cited-finding`. The incident's source check still refuses
merge. Offline fixtures cover a fully cited reversal and refusals for missing
or mismatched publication, unrelated edits and malformed or nonlinear history.

The earlier PR report recorded 93 focused passes. Its full offline run
stopped after exceeding its nominal 900-second validation budget.

This remediation ran nine targeted test files with `node test/run-tests.mjs`.
They reported 354 passes and zero failures, including same-head recovery after
failed reads and preserved reader progress after malformed optional tree data.
`npm run lint` reported zero errors. `npm run typecheck:contracts`,
`bash demo/research-finding-walkthrough.sh`, the data-model catalog validator,
and `git diff --check` passed. PR-head CI owns the full-suite run.
