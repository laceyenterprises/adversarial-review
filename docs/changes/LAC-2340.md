# LAC-2340 — Retain Argus merge retries during lane contention

## Summary

The finalization router can refuse an Argus-approved dependency merge before
the daemon starts when another PR owns the lane. The watcher keeps the completed
security approval and retries under the existing issuance lock and merge lease.
It shares DEPWAIT-01's limit of 18 ten-minute deferrals across merge retry reasons.

The watcher offers one recovery for a legacy approval settled by this
specific refusal. A fresh GitHub read must confirm an open, non-draft,
mergeable PR with green checks at the same head and base branch. The normal
daemon evaluates the current merge gates on each attempt. A moved head,
terminal PR, or permanent refusal cannot recover through the legacy path.

## Interface changes

The existing watcher adjudication API records `result.merge.deferrals` and
optional `notBefore` and `reopenedAt` timestamps on completed drain approvals.
See the [Argus security job data model](../data-model/argus-security-jobs.md).
