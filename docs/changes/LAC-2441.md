# LAC-2441 — Bound native remediation publication

## Summary

The native publisher owns a dedicated process group for each command. A
deadline terminates the group, and leader exit sweeps remaining members even
after they close their capture pipes. Output overflow follows the same
cleanup path. Native pushes select the strict 45-second measured pre-push
tier and reserve that allowance in addition to the load-aware transport
deadline. A fast-check failure still blocks the push. Hosted required checks
still gate merge.

## Interface changes

The publisher verifies the exact remote branch ref after a successful push
command. Interrupted pushes, unreadable refs and mismatched refs use the
existing `remediation-publication-unproven` code. The remote may have accepted
an interrupted push, so recovery checks the live destination before another
write. Lease and credential refusals keep their specific codes.

## Verification

The before-fix fake Git fixture failed because the nested hook survived
leader exit. The offline regression uses a readiness handshake before firing
the timeout and verifies that the nested hook's connection closes. Local bare
Git fixtures cover the exact lease, confirmed delivery, a zero exit with no
remote update, and timeouts with and without a remote update. Fixtures also
cover auth refusal, a failed fast check, output overflow and CLI cancellation.

`node --test --test-name-pattern=LAC-2441 test/remlabel-publication.test.mjs`
passed all nine cases.
