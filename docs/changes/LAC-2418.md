# LAC-2418

## Summary

Count compact live-pack cross-edit findings alongside standard review cards
when validating native remediation replies. The historical failure on
agent-os#11643 reported two findings where review 6056495313 listed three.
The reconciler rejected the reply and the watcher later stopped the job at
the CI retry cap, even though the worker had published `915dcaec`.

## Interface changes

The review-currency reader can return
`verified-stopped-remediation-finding-currency` when the historical accounting
refusal, same-attempt artifacts, exact App push, and live branch ancestry
independently agree. The proof keeps the review's findings applicable.
Withdrawal carry-forward still requires rebase currency, and round completion
still requires the ordinary completion path. See the
[follow-up runbook](../follow-up-runbook.md#finding-currency-after-a-stopped-publication).
GitHub activity is read only after a bounded local scan identifies one
matching historical stop and verifies its recorded round, worker exit, reply
and final message. The source review must match the job's stored body and
reviewer family. The publication and any direct successor must each carry
the stopped job's worker class and job ID. The historical successor
`a326be5d` lacks those trailers, so it does not inherit the publication proof.

## Verification

The stopped-publication tests cover the source review, monthly archives,
direct successors with the same job provenance, and refusals for sibling
reviews and missing, conflicting, withheld or mismatched evidence.

A read-only pre-deploy comparison against the previous parser scanned
24,497 installed follow-up jobs across `completed`, `stopped` and
`stopped-archived`. The 99 jobs with a live-pack marker had 28 persisted
reply copies across embedded payloads and files. Zero replies changed from
valid to invalid, and six previously rejected copies passed with the
corrected finding count.

The hammer-controller timeout test accepts the initial deferred receipt when
the controller stops the validator before its receipt update. Both receipt
forms still require independent evidence of group drain and lease release.

## Final review repairs

The producer and finding parser now share the compact finding title contract,
including names with spaces, slashes or Unicode and escaped Markdown delimiters.
Stopped-job lookup caches only names across readers, bounded to 64 PR keys and
invalidated by partition identity/timestamps. Artifacts are reopened for each
proof. Corrupt matching JSON and capped or changing directory scans refuse
proof with an explicit diagnostic. Tests cover cache reuse and invalidation,
current content reads, corrupt JSON, and producer/parser round trips. The
controller test independently requires its retained cleanup record, including
the controller identity, terminal reason, group drain and lease disposition,
even when the validator only wrote its initial handoff.

The historical `a326be5d` head remains outside the worker publication proof.
This source repair does not reconcile that round or close PR 11643 by itself.

## Reopened after AR #2081

Agent OS #11732 exposed a second case. Its Comment-only worker published
`b0a066e8`, then stopped for an operator-owned SPEC obligation and pending CI.
The closer published `31b2e68e` and the final integration `a9e16ef3` retained
both publications. The old currency reader skipped review `6077235842`
because the stopped round was absent from completed-round evidence and did
not match the historical reply-count refusal.

The shared reader now authenticates that bounded advisory lineage using the
native round's publication and final-artifact receipts, the exact submitted
review, both GitHub App publications and ordered source and final-tree replay.
The resulting proof preserves the review for finding adjudication. The
stopped round, exact-head review requirements and ordinary closure predicates
keep their existing meaning.

The currency reader returns `current: false` when an integration's first
parent lacks the closer commit, even if the integration tree matches. Source
replay stops early when local commit objects and an origin-bound checkout
are unavailable. Offline fixtures cover both refusals.

Rundix #36 is a separate case. The older record stopped with unpublished

publication at `19fdedda` under `lrq_bd4455ba-ff4b-59d5-9ac7-d1fb19b261db`,
but the read-only produced-head chain returned no rows. Delivery of exact
head evidence remains unconfirmed. GitHub later recorded another App force
push from `19fdedda` to `0b8fb89f`.
