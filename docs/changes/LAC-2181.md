# LAC-2181 — HAMADVISORYEDITPLAN-01

## Summary

Strict advisory `in-place` plans previously fell through to `edit-kind-invalid`.
The pre-edit helper now distinguishes the recognized but disallowed category as
`stop/advisory-in-place-disallowed`. The hammer prompt and closure runbook explain
blocking/CI repair categories, safe re-planning, strict stops and non-strict
durable backlog deferrals under existing policy.

## Interface changes

The strict advisory in-place stop reason changes; action `stop` and CLI exit 1
remain unchanged. Unknown categories retain `edit-kind-invalid`. No policy,
storage, live runtime or PR #1769 changes. Exact-head review evidence,
reviewed-coordinate coverage, additive preservation, reversal provenance and
final merge predicates retain their existing requirements.
