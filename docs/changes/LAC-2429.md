## Interface changes

`reviewed-native-publication-main-integration` can carry findings from the
latest applicable review only when the original bound native publication
replays, the one `main` integration tree replays exactly, and every other
first-parent successor has independent publication authority. This proof
does not satisfy `rebaseCurrencyCovers`. The read-only PR blockers report can
name refused evidence when supplied a checkout. No lifecycle or smoke
contract changes. The collector accepts an optional `createCurrency` dependency
for isolated currency-result regression fixtures; production retains the shared
reader. [Owner runbook](../RUNBOOK-ama-closure.md#retained-repair-publication-followed-by-main-integration)
