# LAC-2303 — Consume the canonical CWP repair fence

## Summary

The HQ-owner retirement command now consumes the deployed CWP
`cwp-repair-retirement-proof` for an original conflict reservation whose PR
head has moved. It reads matching committed owner and epoch receipts, checks
global family absence and PR-wide custody, and revalidates the original
submission and reservation under the shared locks before recording retirement.
The original legacy handoff variant is still supported.

## Interface changes

The CWP variant of `bin/retire-legacy-repair.mjs` takes `--current-head`,
`--conflict-worker-id` and `--boot-trace-offset` alongside the existing
repo/PR/base/epoch/owner selector. The legacy variant continues to take
`--handoff-round`. Both variants retain the proof and accounting history on the
original epoch. [Operator runbook](../RUNBOOK-ama-closure.md#retire-one-fenced-cwp-conflict-reservation-lac-2303)
