# LAC-2353 — Reduce repeated config work in the Node 22 suite

## Summary

The full Node 22 job on `03d836afc` selected 960 files and reached 900
seconds with 331 queued and eight active.
Node 26 finished on that head. The earlier `b27680aab` jobs finished 959 files
in 804.255 seconds on Node 22 and 666.053 seconds on Node 26. Those runs show
how much headroom can vary after the earlier environment cache-key fix.
[Node 22 job](https://github.com/laceyenterprises/adversarial-review/actions/runs/45510086123/job/138855256033)
· [Node 26 job](https://github.com/laceyenterprises/adversarial-review/actions/runs/45510086123/job/138855256486)

A local Node 22 CPU profile of the 180-poll watcher fixture sampled about
1.33 seconds cloning code defaults and their provenance across three cold
loader call sites, and about 0.47 seconds walking schema paths from the
cascade. The loader now serializes its code-default graph when building it
for the selected schema and deserializes it for each load. Each load owns
its values and provenance, with the original shared references within that
load. The snapshot contains only schema-derived defaults. The env layer
skips rows with no supplied alias before schema lookup. Supplied aliases
still go through the selected schema, conflict checks and coercion in their
original order.

## Interface changes

None. The schema source, cascade and provenance contracts, and suite
selection and deadline stay the same.

## Verification

Three alternating before/after pairs on macOS arm64 used Node 22.22.3,
eight workers and the normal offline runner. The baseline cascade came
from `03d836afc1bbf9d6ecbb1dc69bcdc028b2a310f4`. Both sides ran the same
test files and assertions.

| Measurement (seconds) | Before | After |
| --- | --- | --- |
| Eight-file cohort wall time | 7.997, 7.676, 8.046 | 6.755, 6.697, 7.429 |
| Watcher poll-memory file | 7.961, 7.648, 8.017 | 6.726, 6.672, 7.397 |
| Sum of eight file durations | 15.302, 15.010, 16.009 | 14.180, 13.098, 16.026 |

The median cohort wall time fell 15.5%. Ordered TAP identities and all
615 passing outcomes matched in every run. The cohort was
`watcher-poll-memory`, `config-loader`, `config-cfg-parity`,
`config-schema-source`, `role-config-cache`, `config-loader-profile-overlay`,
`config-identity-token-pools`, and `config-public-hygiene`. The mutation
assertions cover fresh defaults and shared value/provenance references
within a load. The schema-source assertions cover live default replacement,
fallback to the bundled schema, and alias conflicts across that boundary.
Repository and changed-file lint passed with zero errors. The contract
typecheck and the offline walkthrough passed. The walkthrough produced
three byte-stable transcript deliveries.
