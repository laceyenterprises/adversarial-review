# LAC-2246

## Summary

Extend the LAC-2127 certificate for the Agent OS ledger’s 340-to-341
migration renumber through the second main merge on PR #11143. Each later
second parent must advance the previous main parent, belong to the observed
trusted main ancestry, and match the original RSS main’s migration tree.
The last integrated parent must match the PR comparison merge base.
The exception is selected only when the first merge integrates the recorded
RSS main parent; other integrations retain the general snapshot proof path.

## Interface changes

`mainIntegration` includes the `comparisonMergeBase` and ordered
`additionalMainParents` commit and tree IDs. The certificate retains every
first-parent snapshot and the original applied-parent wrapper, registry, SQL
and operation bindings. The native evaluator consumes the original certificate
in the evaluation that issued it. Retire this extension along with the
LAC-2127 exception once Agent OS PR #11143 is merged or closed.
