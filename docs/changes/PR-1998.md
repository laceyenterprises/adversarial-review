cache: support inventory predicates and boolean patch flags, normalize SHA
casing, and project scoped file rows from cached full comparisons. Keep
inventory checkpoints separate so they cannot masquerade as full patch evidence.

## Interface changes

`compareFiles` accepts boolean patch flags as well as path predicates, with
patches enabled by default. `storedHistoryRead` without a compute callback is a
lookup-only operation returning `undefined` on a miss. Complete full-patch and
inventory projections use distinct head/host-scoped checkpoint keys; the
canonical data-model contract and closure runbook describe their reuse.
