## Shared review database bootstrap for PR #1983

### Summary

Initialize a fresh review-state SQLite database in one transaction. The
runner repeatedly exercises this path in isolated fixture roots, including
terminal remediation tests that call `recordRemediationPassTerminalSafe`,
then `completeReviewerPass`, then `ensureReviewStateSchema`. Previously, many
of the statements that create tables, columns and indexes ran in autocommit.

### Interface changes

Fresh schema setup, including repository identity tables and migration
receipts, commits or rolls back as a unit. A connection that initially sees an
empty schema rechecks the schema version under the writer lock. It skips DDL
after a peer finishes bootstrap and completes any partial schema within the
transaction. Identity setup is memoized once the tables are committed.
Databases with a schema already visible on the first check use incremental
migrations under the configured busy timeout.

The complete-schema and partial-schema race fixtures interleave two real
SQLite handles at writer-lock acquisition. The complete-schema fixture
asserts that the second handle issues no DDL. The partial-schema fixture
asserts that all installation DDL stays inside the transaction. Both and the
rollback fixture check that subsequent identity lookups reuse committed setup.
The three regression checks failed on the reviewed head. On Node 22.22.3,
`node test/run-tests.mjs test/review-state*.test.mjs test/repository-identity.test.mjs`
passed all 93 tests with the fix.

then checks that only the held file remains active and zero files are queued.

messages before firing the synthetic deadline. The coordinator skips progress
messages after disconnect and handles a concurrent send failure through its
callback; an IPC-disconnect regression verifies native workers finish and publish
their file report.

that the production executor converted into deferrals. The regression injects
property assignment, array insertion, property deletion and array reversal in a
leased read, exercising the real executor catch. Ordinary synthetic read outages
