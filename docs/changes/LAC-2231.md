# LAC-2231 — Route final remediation to closeout

## Summary

Follow-up completion receipts retain durable review admission and follow the
normal deduplication and review ceilings. A genuine operator request retains
priority when it shares the same head with a worker request. At a settled
Comment-only ceiling, or after a delivered final pass that started after the
remediation budget was spent, watcher intake can restore the delivered source
review for the closer and settle the worker receipt atomically.

A proven final fix-all publication transfers to the exact-head closer. The
closer still validates original finding dispositions, source preservation and
required CI. [Incident report](../postmortems/LAC-2231-worker-completion-reopened-final-review.md)

The operator-directed final-round contract intentionally replaces LANEAUTO-01's
post-publication automatic full review for a bound, proven final fix-all push.
This reduces independent review coverage: base synchronization, including any
conflict resolution in that fix-all publication, receives closer validation
rather than a new cross-model pass. The closer must validate every original
finding disposition, primary-source preservation and exact-head required CI.
Separate tenure and conflict-primary review requirements and attributable
operator review requests retain their existing authority. This round does not
introduce a new diff-scope merge predicate or a conflict-merge review exception.

## Interface changes

New `final-fix-all` work orders record `closureHandoff.review: closeout`.
Existing `full` fix-all orders qualify under the same source and publication
proof. The existing receipt and job statuses carry the handoff.

The worker prompt now requires a disposition and validation evidence for every
finding and describes the closer handoff without another automatic review.
Cycle-cap routing, terminal closer-head restoration and same-head budget
restoration settle worker receipts under a matching row snapshot; a concurrent
priority request retains its receipt. Fleet-self-repair declines use the same
atomic settlement. Capped admission leaves `ci-blocked` rows and their failure
evidence to CIBLOCKHAM. Closeout compares source, publication and CI SHAs without
case sensitivity.
Pending-intent SQL fences remain enforced: the worker receipt is settled before
restoration inside the transaction, and both settlement and row changes roll
back on a failed comparison or exception. This also repairs the existing
reviewed-head dedup restoration with a pending worker receipt.
