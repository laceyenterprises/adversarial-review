# LAC-2202 — primary-change provenance after a conflict rebase

## Summary

Recover existing commit trailers before a standard terminal Git conflict
footer. PR 10916's rebased hammer commit retained its identity and finding
citations, but the `; Conflicts:` suffix hid every trailer. Classification
fell through to the untagged-launch check, whose original SHA was absent from
the rebased history. The actual first hammer parent remains the protected
author head; stale launch records do not replace it.

The [RCA](../postmortems/LAC-2202-primary-change-provenance.md) compares
LAC-2141 and PRIMARYCHG-01 and records read-only deployed evidence.

## Interface changes

The shared trailer reader accepts only a terminal `# Conflicts:` or
`; Conflicts:` suffix containing same-marker tab-indented paths and optional
blank/comment-only lines, including comment-only lines with trailing spaces
or tabs. Earlier conflict headings in the commit body do not
hide a valid terminal suffix. Duplicate identity rejection and all independent
preservation, citation, author identity, rebase and reversal proofs remain.
Unsupported trailing prose and unproven untagged history still fail closed.

Completed history identity advances from `reversalproof-v7` to
`reversalproof-v8`, recomputing old classifications through normal convergence.
The canonical `docs/data-model/catalog.json` records the v8 identity.
No CLI, config, lifecycle, CI job, merge exception or live audit mutation.

## Recurrence on 2026-11-19

Agent OS #11143 reached `72250e9c` after another conflict rebase. The
first hammer commit, `89dfa3f3`, carried two consecutive `; Conflicts:`
footers. The deployed single-footer reader still hid its real trailers, so
the collector fell back to the earliest persisted launch, `f4c06bc7`.
GitHub reports that launch as diverged from the initial authoritative review,
`2367f015`, and the launch SHA is absent from the current PR compare. The
untagged fallback correctly refused those inputs.

The shared reader now validates and removes each consecutive terminal
conflict section. The collector can then select the actual first hammer parent,
`19aa526c`, which includes the builder remediation. The v9 cache identity
recomputes completed histories that could have selected a later hammer parent.
Truly untagged and malformed histories still require the existing launch and
builder proof. Trailer recovery never substitutes for reversal authorization,
primary-change preservation, review or CI.

records the persisted launch, compared history and read-only replay. The offline
