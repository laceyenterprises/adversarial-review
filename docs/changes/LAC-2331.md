# LAC-2331 — Review currency across native remediation and Hammer rebases

## Summary

Agent OS PR #11456 had an authoritative review on `97435b07`, a daemon-completed
native remediation at `f879b8d2`, and an authenticated Hammer publication at
`9f801d05`. The shared review reader omitted the native round, and the Hammer
range validator tried each source independently. Both lost the reviewed head
when the rebase removed it from Git ancestry.

Both paths now use the daemon's completed-job records and authenticated Hammer
comments to prove a chain ending at the exact live head. Repeated rebases can
extend the chain through additional exact Hammer edges. Source preservation
and reversal authority remain separate merge checks.

## Interface changes

The shared reader and Hammer range validator take the local review service
`rootDir` for completed rounds. The range validator also takes `prNumber` and
reads the protected records directly. The completed-job schema stays the same.

## Verification

The two offline reproduction cases failed on unfixed main. The fixtures also
exercise repeated rebases, missing and malformed records, wrong repo and PR,
forged authorship, endpoint tampering, branch resets, and independent patch
proof after a capped comment read.

The isolated regression and daemon-audit suites passed all 38 tests after
reusing the canonical source-reversal fixture. The 11-file offline run passed
577 of 578 tests before that fixture correction, including the watcher claim
loop and state-machine smoke. Lint passed with zero errors, contract typecheck
passed, and the walkthrough produced three byte-stable deliveries.
