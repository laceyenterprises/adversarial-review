## Interface changes

receipts beyond run scratch. Unsafe or unreadable custody holds its target and
asks for one operator decision. A clean matching-target source with confirmed
cleanup is marked continued and returns to existing per-head retry backoff and
notification. Legacy retry entries alone and corrupt retry files do not hold
unrelated heads; new unsafe observations retain explicit `custodyRequired`
fallback evidence. Corrupt retry files remain preserved for recovery.

Teardown retries incomplete bundling before refusing reclamation and omits
unavailable prerequisites so it can create a self-contained bundle. A missing
source receipt can establish matching-target source only when cleanliness is
not explicitly false. Continuation waits up to one second for a contended lock;
the controller retries post-publication completion three times without another
push. Standalone UNKNOWN accepts an all-local-pass selection without CI coverage
identity, while every UNKNOWN merge still requires declared green exact-head
contexts, including legacy receipts. Tests use stable exact assertions at the
Node 22.10 engine floor and pin controller coverage/cleanup fields.

## Final Comment-only remediation

### Summary

Document that standalone native recovery of an already published SHA does not
produce closure-resume authority: an operator must merge that same head under
the normal gates, keeping automatic admission paused until closure is confirmed.
The clean matching-target custody tests now contrast refusal-only holds with
ordinary continuation; dirty-byte retention remains separately covered.

### Interface changes

The mirror also recognizes exact Python/Node no-verdict components in the
guard's semicolon-separated result reason. Unrelated checks and decorated
non-matching reason text retain their prior classification. Legacy receipt
classification uses a bounded process-local cache keyed by source head and file
identity, size and nanosecond modification/change timestamps. Re-observation
still stats the receipt; changed or missing evidence invalidates reuse. No
durable store fields, lifecycle transitions, merge gates or smoke promises change.
