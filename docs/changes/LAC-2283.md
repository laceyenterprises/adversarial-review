# LAC-2283

## Summary

A GitHub 401 interrupted guarded remediation publication with the worker's
commit still local. The worker reported `kind: github-auth`, which the strict
reply validator rejected. The guarded publisher now supplies a reply-ready
blocker and records the exact commit and remote lease independently of reply
validation.

An exited round with a current auth, broker or stale-lease refusal holds for
owner recovery. The consumer verifies the checkout and saves a verified
bundle where ownership permits. A running worker keeps custody. Invalid
replies remain invalid and cannot request re-review.

## Interface changes

The publisher accepts `--job-id` for follow-up invocations and
`--expected-candidate` for an explicit recovery attempt. Failure sidecars
include job and PR identity, the exact lease and the reply-ready blocker.
The stopped job records the refusal and retained source evidence. [Refusal evidence contract](../data-model/follow-up-jobs.md#refused-remediation-publication-remlabel-01)
