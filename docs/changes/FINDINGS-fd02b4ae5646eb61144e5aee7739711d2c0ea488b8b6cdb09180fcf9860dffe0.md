# Deterministic merge lease CLI polling

## Summary

The capped-polling test supplies a fixed process start time for its simulated
lease holder. A synthetic PID reuse reproduced reclaim at 3,750 ms while the
test still reported the holder alive. The fixed start time keeps reclaim at
the simulated death at 45,750 ms.

Final review remediation guards the process mock's argument match with
`Array.isArray(args)`, preserving the `execFileSync(command, options)` overload.
The CLI calls reclaim and inspection directly without forwarding a process-capture
dependency, so this test retains the scoped module mock and its restoration hook.
