# LAC-2451 — Bound reviewer process scans for busy hosts

## Summary

The full-width process list can exceed Node's default 1 MiB output buffer.
Reviewer claim recovery now allows up to 8 MiB for that scan. A failed or
oversized read still leaves process ownership unknown.

## Interface changes

None.

## Verification

The watcher reattachment tests cover a matching reviewer after more than
1 MiB of unrelated output and the unknown result on a failed scan.

The new regression failed with the original output limit. All 96 reattachment
tests passed with the revised limit. ESLint, contract type checking and the
offline research finding walkthrough also passed.
