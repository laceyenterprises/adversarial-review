HAMLATEAUDIT-01 binds terminal remediation authority to current applicable review
evidence as well as the validated SHA. The closer selects findings using the
canonical authoritative-family ancestry rules. At initial predicate evaluation,
the final hammer gate and daemon terminal-audit reuse, each family's latest
applicable head/body is compared with its applicable head/body when the
authenticated audit was published.

Changed evidence returns `review-changed-since-validation`; absent or unreadable
proof refuses authority. Identical same-head review bodies retain validation
despite new review IDs or timestamps. Inapplicable authors, pending reviews and
discarded branches retain existing canonical rules. Missing ancestry is unknown,
never proof that a review is inapplicable.

This adds no review request, execution path, lease transition, configuration,
CI runner or authority waiver. Existing merge predicates consume the proof
refusal alongside the existing exact-head, lease and required-check gates.

The REST snapshot reader accepts a review-selection callback evaluated after
checks. Hammer paginates reviews only at a green, open, matching-head gate,
adding a review-page read at each existing green gate (two in the common-close
fixture) and none to pending-CI polls.
