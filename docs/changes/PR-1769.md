# PR-1769 — durable GitHub installation budget bindings

## Summary

Route persisted installation bindings through the GHSTATEOWNER-01 store plan.
Create private binding directories and reject foreign owners and symlinks before
trusting a binding, subject to the documented trusted-parent assumption.
Resolve configured process store paths centrally for all binding lookups,
including allowlisted environments, without inheriting process tokens into
adapter accounting. Cache missing bindings for one second per store path and digest, with a
256-entry bound. Move binding regressions into the normal test discovery path.

## Interface changes

`resolveBudgetBindingDirectory` exposes the existing owner-selected store path
with its `.bindings` suffix. Binding files retain `{ digest, credential,
expiresAt }`, 0600 atomic writes and a maximum one-hour lifetime; the canonical
data-model document and catalog now describe their cross-process, same-uid
resolution, ownership boundary and expiry/pruning behavior. Caller store paths
take precedence over process paths; absent/null paths inherit the process path.
Successful disk reads remain uncached for immediate ownership/expiry
revalidation. The directory check does not fence concurrent replacement by a
parent-directory writer, and crashed-writer temporary files require separate
cleanup. Existing lifecycle
states and smoke promises are unchanged.
