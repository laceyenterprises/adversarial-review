# LAC-2293 — Serialize automatic verdict claims with native merge custody

## Summary

On #1986, an automatic verdict-only reviewer claimed the same head after the
native merge holder passed its under-lease owner check. The final native gate
refused the operation. The watcher now uses the same per-base mutation lock as
native lease acquisition when it claims an exhausted-head system request.

## Interface changes

`native-merge-custody`, `merge-lease-mutation-busy` and
`merge-lease-base-unavailable` are watcher claim deferrals. A deferred request
keeps its row, intent and attempt budget. A claim that commits first stays
visible to the existing native owner check. The fence grants no findings,
review, CI or source-preservation authority. It uses the existing lease schema.
An exact system marker also binds a legacy pending row after subject identity
backfill clears `revision_ref`. A conflicting revision prevents the match.

## Verification

The offline baseline replay used the production lease grant and SQLite claim
CAS. It reproduced late claims 12/12 with an existing holder and 12/12 with a
grant after a standalone precheck. When the claim ran first, the initial
under-lease review check saw the claim 12/12.

| Deterministic case | Before | After |
| --- | --- | --- |
| Existing holder and grant after precheck | Late claim 12/12 each | Late claim 0/12 each, pending request resumes after release |
| Review claim first | Claim visible to the under-lease check 12/12 | Claim visible 12/12, competing grant defers until commit |
| Matching holder with unknown local identity | Claim 12/12 | Pending and uncharged 12/12, including past deadline |
| Different PR, wrong head, expired remote or dead local holder | Claim 12/12 each | Claim 12/12 each |
| Pending human request, initial review, failed review retry | Claim 12/12 each | Claim 12/12 each |
| Missing review row | CAS changed zero rows 12/12 | CAS changed zero rows 12/12 |
| Exhausted cycle with unresolved findings | Strict merge refused 12/12 | Strict merge refused 12/12, deferred claim resumes after release |

`node test/run-tests.mjs test/lac2293-merge-review-custody.test.mjs
test/watcher-pending-failure-claim.test.mjs` passed 215 tests.
Lint passed with zero errors, contract typechecking passed, and the offline
walkthrough reproduced three byte-stable deliveries. Production acceptance
requires a live exact-head closeout receipt after normal deployment.
