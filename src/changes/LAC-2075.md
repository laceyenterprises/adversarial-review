# LAC-2075

Budget admission and header observations follow the credential that sends each
GitHub request. This covers the watcher intake discovery wrapper, the watcher's
own telemetry wrapper, `execGhJson` read preflight and success/error headers,
the `github-api` adapter-read wrapper, comment lookup and write, review-body
capture, the live PR lifecycle lookup and the raw-blob diff fetch. A low
anonymous `default` bucket no longer defers an authenticated token, and one
token neither borrows another token's budget nor poisons it. A low or zero
budget for the sending token still defers. Adapter reads share the label
executor's credential derivation through `githubAdapterReadCredential`.

The `reviewer.mjs` review-post preflight is deferred until PR 1702 (LAC-2151)
merges. See the [SEV3 report](../../docs/postmortems/SEV3-LAC-2075-authenticated-github-reads-deferred-by-the-anonymous-budget-2026-11-03.md).
