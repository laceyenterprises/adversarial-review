# LAC-2101 — Consume Agent OS legacy generated-file preservation proofs

## Summary

Primary-change collection can resolve a region refusal on three legacy Agent OS
JSON files with a read-only, bounded verification from the deployed Agent OS
owner. The consumer compares complete immutable blobs from the history reader
and registered object store. It passes the producer's exact version-1 evidence
tuple to the predicate, which still checks every other author path.
Final comment-only remediation uses Linux `--ro-bind-try` for auxiliary
read-only mounts, allowing absent optional producer libraries without changing
the verifier's fail-closed result or granting write access.

## Interface changes

Successful primary-change decisions can include `legacyGeneratedPreservation`,
an array of exact version-1 tuples. Local proof failures leave the original
predicate refusal in place. Deploy the producer before activating the consumer.
The invocation, allowlist and refusal rules are in the
[AMA closure runbook](../RUNBOOK-ama-closure.md#legacy-generated-preservation-lac-2101).
