# LAC-2418

## Summary

Count compact live-pack cross-edit findings alongside standard review cards
when validating native remediation replies. The historical failure on
agent-os#11643 reported two findings where review 6056495313 listed three.
The reconciler rejected the reply and the watcher later stopped the job at
the CI retry cap, even though the worker had published `915dcaec`.

## Interface changes

The review-currency reader can return
`verified-stopped-remediation-finding-currency` when the historical accounting
refusal, same-attempt artifacts, exact App push, and live branch ancestry
independently agree. The proof keeps the review's findings applicable.
Withdrawal carry-forward still requires rebase currency, and round completion
still requires the ordinary completion path. See the
[follow-up runbook](../follow-up-runbook.md#finding-currency-after-a-stopped-publication).
GitHub activity is read only after a bounded local scan identifies one
matching historical stop and verifies its recorded round, worker exit, reply
and final message. The source review must match the job's stored body and
reviewer family. The publication and any direct successor must each carry
the stopped job's worker class and job ID. The historical successor
`a326be5d` lacks those trailers, so it does not inherit the publication proof.

## Verification

The stopped-publication tests cover the source review, monthly archives,
direct successors with the same job provenance, and refusals for sibling
reviews and missing, conflicting, withheld or mismatched evidence.

A read-only pre-deploy comparison against the previous parser scanned
24,497 installed follow-up jobs across `completed`, `stopped` and
`stopped-archived`. The 99 jobs with a live-pack marker had 28 persisted
reply copies across embedded payloads and files. Zero replies changed from
valid to invalid, and six previously rejected copies passed with the
corrected finding count.

The hammer-controller timeout test accepts the initial deferred receipt when
the controller stops the validator before its receipt update. Both receipt
forms still require independent evidence of group drain and lease release.
